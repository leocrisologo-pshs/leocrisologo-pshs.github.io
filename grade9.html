The Remainder and Factor Theorems

In this lesson we show that the remainder of a polynomial function divided by a linear binomial (x - c) is equal to the value of the function evaluated at c. We call this the Remainder Theorem. An implication is that if c is a zero of a polynomial function, i.e. f(c)=0, then (x - c) is a factor of the polynomial. The converse is also true. We call this the Factor Theorem. This is part of the second quarter lessons for PSHS Math 3.
