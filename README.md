# Leo's Repository

A simple, public GitHub Pages resource collection.

## Publish

1. Create a **public** repository named `leocrisologo-pshs.github.io` (if your username has changed, use the new username in that name).
2. Upload the **contents** of this folder into the repository root, including the hidden `.nojekyll` file. Do not upload only the ZIP or a nested folder.
3. In GitHub, go to **Settings → Pages → Build and deployment → Deploy from a branch**, choose **main** and **/(root)**, then save.
4. Visit `https://leocrisologo-pshs.github.io/` after GitHub finishes publishing (change the username if applicable).

## Maintain

- Edit `index.html` to change the homepage cards.
- Edit `mathematics.html`, `teaching.html`, `research.html`, `code.html`, and `explore.html` to add entries.
- Replace the placeholder `<span class="placeholder">Link to be added</span>` with a real link, for example `<a href="https://example.com">Open ↗</a>`.
- Modify `style.css` if you want to change the layout, fonts, or colors.
- Existing GitHub repositories do **not** have to be moved into the website repository.

## Privacy reminder

Everything uploaded to this public Pages repository should be treated as public. Do not add private class materials, passwords, answer keys, restricted readings, or private workspace links. Store restricted materials in a separate private repository or an access-controlled folder instead. GitHub Pages does not provide ordinary per-page password protection.
